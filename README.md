# AI記事作成サポート（AI Article Assistant）

WordPressで記事の条件を整理し、ChatGPTとの手動相談から、CSV・画像・PDFを使った下書き登録までを支援するプラグインです。

**OpenAI APIキーは不要です。** 相談文をコピーし、利用者が自分のChatGPT環境へ貼り付けます。ChatGPTの利用料金、画像生成、リサーチ、生成ファイルのダウンロードやZIP化の可否は利用環境によって異なり、本プラグインは提供・保証しません。

## 主な機能

- 記事の概要・種類・カテゴリー・資料をもとにした相談文の生成。
- 段階的な相談、なるべくAIにお任せ、添削、ネタ・タイトルだけの相談。
- 管理者設定のカード型UIと、基本・詳細・特定項目のAI設定相談。
- 設定CSVの差分比較、連続適用、競合の追加承認、カテゴリー作成の明示承認。
- 記事CSV v2と旧形式の読み込み、画像・PDFの対応付け、アイキャッチとダミー画像。
- Gutenberg標準ブロックへの変換と下書き作成。公開はWordPressで利用者が行います。
- 記事制作IDによる重複登録防止、投稿者プロフィール、許可した公開記事の参照、任意のACF連携。

## 動作要件

- WordPress 6.3以上、PHP 8.0以上（JSON拡張が必要）。
- 投稿作成には投稿権限、ファイル登録にはアップロード権限、設定には管理者権限が必要です。
- ブロックエディターを基本とします。すべてのテーマ・追加プラグインとの互換性を保証するものではありません。
- GitHub更新には、WordPressからGitHub APIおよびReleaseファイルへのHTTPS通信が必要です。

## インストール

1. [GitHub Releases](https://github.com/cni-works/ai-article-assistant/releases) の正式版から、添付された **ai-article-assistant.zip** を取得します。
2. WordPressの「プラグイン→新規追加→アップロード」からZIPを選んで有効化します。
3. 「AI記事作成サポート→管理者設定」でサイト情報・記事の種類・投稿先などを確認します。詳細相談は任意です。

GitHubの「Source code (zip)」やリポジトリ全体のダウンロードは更新用ZIPと区別してください。プラグインの固定パスは `ai-article-assistant/ai-article-assistant.php` です。

## 記事制作の流れ

1. STEP1で目的・概要・進め方を選び、相談文を生成します。
2. STEP2で相談文をコピーしてChatGPTへ貼り付け、必要な事実確認、構成・本文の承認を進めます。
3. 必要な画像は1枚ずつ制作・承認します。画像が不要な記事は省略します。通常は本文・画像計画の最終確認後に記事CSVを1回生成します。
4. CSVと必要ファイルを受け取り、STEP3で記事CSVを読み込みます。ZIPで受け取った場合はパソコンで展開します。
5. 画像・PDFを登録するか既存メディアを選び、識別子・用途・サムネイルを確認して対応付けます。同名ファイルだけで既存画像を自動確定しません。
6. STEP4で投稿先・カテゴリー・未登録画像などを確認し、下書きを作成します。標準エディターで編集・表示を確認し、利用者が公開します。

画像が未準備の場合は、保留や承認したダミー画像の仮配置を選べます。ダミーは通常の画像ブロックの「置換」で変更できます。本文や独自体験、料金・制度などの未確認事項をAIに創作させず、出典と事実を確認してください。

設定CSVと記事CSVは別形式・別の取り込み画面です。設定CSVは読み込んだだけでは保存されず、比較・必要な追加承認・適用後に保存されます。

## 更新方法

初回にアップデーター付き版を手動で導入すると、その後はWordPressのプラグイン一覧・更新画面から正式版の通知と更新操作を利用できます。既に入っている版にアップデーターがなければ、最初の手動更新が必要です。同じ0.1.0同士で更新通知が出ないことは正常です。

Plugin Update Checker 5.7を同梱し、このリポジトリの正式Releaseと指定名の添付ZIPだけを参照します。プレリリース、下書き、添付ZIPのないRelease、タグ・本文のバージョンが一致しない更新は対象にしません。タグだけ・mainへのPushだけでは配信しません。GitHubトークンは不要で、配布物にも含めません。

通常は約12時間間隔のチェックとWordPressの更新操作を使います。WP-Cronの実行頻度・通信制限・GitHubのレート制限によって通知時期は変わります。独自にバックグラウンド自動更新を強制しません。WordPress管理者が選択した自動更新方針に従います。

更新前にDB・uploads・現在のプラグインZIPを控え、検証サイトで確認してください。更新機構は既存の記事・画像・設定を削除する移行処理を追加していませんが、通信・ファイル権限・サーバー障害を含む更新失敗からの完全復旧は保証しません。

## プライバシー・通信

記事制作機能からChatGPTへ自動送信しません。相談文をコピーして貼り付けた内容は、そのサービスの規約・設定に従って扱われます。機密情報を入力・共有しないでください。

アップデーターはGitHubへバージョン情報・ライセンス表記・更新履歴などの取得要求を送り、更新時に配布ZIPを取得します。通常のHTTPアクセス情報はGitHubへ伝わります。記事本文・画像・サイト設定を更新確認のために送信する実装はありません。WordPress本体や他プラグインの通信はそれぞれの方針に従います。
