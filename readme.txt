手動でChatGPTに相談しながら記事を作り、専用CSVから新規下書きへ取り込む開発版です。Phase 4の画像・PDFリンク・表に対応しています。実WordPressでの一括確認は未実施です。

Phase 5のうちACF連携を追加しました。ACFの実インストール環境での確認は後日行います。

== Description ==

現在利用できる機能：
* 管理者設定トップの保存状況・カード式設定一覧。保存状態に応じて初期設定または確認・編集を優先。
* AIによる初期設定を準備→相談文コピー→CSV比較・承認・適用の3ステップに整理。
* サイト情報・カテゴリー・記事の種類・詳細方針を選ぶ限定相談。既存の基本・詳細相談とCSV形式を使用。
* 設定CSVの大きな選択ボタン・ドラッグ＆ドロップ、保存済み設定と未適用比較の区別、適用後の件数とトップへ戻る操作。
* 初期設定相談ではブログの役割を確認し、相談継続と保留を区別。カテゴリーの目的・名前・スラッグ・記事の種類を合わせて検討。
* 有効な記事の種類と実際の投稿権限に応じた選択肢、説明・資料・追加質問の切り替え。
* 記事の種類ごとの既存投稿タイプ・標準カテゴリーの指定と実在性の検証。
* 同じ質問定義・文章ルールを利用者画面とAI相談に反映する共通処理。
* 新画面から保存する記事の設定スナップショットと、明示的な最新設定の採用。
* 「記事を作る」「使い方」「管理者設定」に整理したメニュー。
* AIへの初期設定相談プロンプトと、承認した初期設定専用CSVの確認・適用。
* 初期設定の部分更新、新規記事の種類追加、既存カテゴリーの方針、変更前の控え。
* 「書きたいことが決まっている」「何を書くかから相談したい」の選択。
* 短い概要からの仮テーマ作成と、テーマ未定・概要未入力からの企画相談。
* サイト基本情報・文章ルール・禁止事項の保存。
* 通常投稿・公開カスタム投稿タイプの選択。
* カテゴリー・タグ等の既存分類へのAI相談用追加情報。
* 記事の種類の作成・編集・複製・削除。
* 5種類の編集可能な初期記事の種類。
* 利用者ごと・サイトごとの記事作成条件の保存・復元。
* 自分の担当・サービス・経験・考え方・文体を保存する投稿者プロフィール。
* 個人情報の項目ごとの利用範囲（使わない／AIの参考のみ／記事への掲載可）。
* 個別条件の優先と管理者専用ルールの保持。
* 概要入力と確認の2段階によるAI相談プロンプト生成。
* 記事の種類別ルールと制作モード（AIの推奨／管理者固定）。
* 制作判断、ヒアリング、調査、構成承認、原稿・品質確認を案内する相談ルール。
* 手動コピーと、プロンプト版・部品ハッシュ・生成日時の保存。
* 貼り付け直後から、質問・資料添付・原稿承認・CSV取り込みへ順に誘導するAI向け案内ルール。
* 承認済み原稿のCSV出力用プロンプト。
* UTF-8専用CSV v1の検証・プレビュー・新規下書き登録。
* 段落、H2/H3、リスト、引用、区切り、ボタン、表の標準ブロック変換。
* 表の列見出し・説明文、最大12列・データ100行、形状検査とプレビュー。
* 今回の記事の画像・PDFの識別子とメディアIDの対応表（最大20件）。
* 標準メディアからの選択、未アップロード資料の説明先行登録、後からの対応付け。
* 画像のalt・キャプション、PDFリンク・任意のダウンロードボタン、画像1件のアイキャッチ。
* 未配置資料・必須資料の警告と、本文に残す確認用の段落。
* 管理者が投稿先ごとに明示的に許可する、任意のACF連携。
* ACFの文字・数値・選択・真偽値・画像・PDF・単純なグループの型検証と新規下書き保存。
* ACF定義変更時の再確認、保存後の値とフィールド参照の照合。
* 本人の管理ID付き下書き1件を明示的に選ぶ、タイトル・本文・抜粋の更新。
* 更新前後の差分、更新前の控え、実行済み確認と条件付き保存による競合時の停止。
* 管理IDとスラッグの重複防止、実行直前の再検証、二重実行防止。

既存記事の更新は、本人の管理ID付き下書きの3項目だけに限定します。公開記事、画像・PDF・独自ブロックを含む本文、保存連携が必要なサイトはWordPress標準エディターを使用してください。ACFの複雑なフィールド・条件付き項目・制限付きメディア、表のセル結合・入れ子・セル内リンク、PDF埋め込み・内容の自動読取、外部メディアの自動取得は扱いません。対応表は本人・サイトごとに現在の記事1件分で、新しい記事の開始でリセットします。プラグインから外部AIへの通信・API呼び出しは行いません。調査や原稿作成は、利用者がChatGPT側で進めます。公開はWordPress標準画面から利用者が行います。

== Installation ==

1. テスト用WordPressでZIPを「プラグイン → 新規追加 → プラグインのアップロード」からインストールします。
2. 有効化後、管理者が「AI記事作成サポート → 管理者設定」でサイト共通情報と投稿先を確認します。
3. 「AIと相談して初期設定する」からプロンプトをコピーし、ChatGPTの質問に回答します。提案を承認して初期設定用CSVを受け取り、管理者設定で比較・確認して適用します。個別画面での設定も可能です。
4. 必要に応じて「個人設定・投稿者プロフィール」で本人の情報と利用範囲を保存します。
5. 「記事を作る」で相談の始め方と記事の種類を選び、「概要を保存して相談プロンプトを作る」を押します。テーマから相談する場合は概要なしでも開始できます。必要な確認が揃っていれば保存と同時に生成し、確認・プロンプト出力で内容を確認できます。既存記事の確認が必須の場合などは入力を保存して次の操作を案内します。
6. 生成したプロンプトを手動コピーしてChatGPTに貼り付け、対話を進めます。
7. ChatGPTで本文と画像・PDF計画を確認し、画像を1枚ずつ制作・採用承認します。全体の最終確認後、記事CSV v2を通常1回だけ受け取ります。画像不要なら画像工程を省略し、途中CSVは画像を後から準備したい場合の明示希望だけで出力します。
8. 「完成した原稿を取り込む」で記事CSVをアップロードし、画像・PDFを標準メディアでまとめて登録・選択して、各識別子へ明示的に対応付けます。
9. プレビュー・警告を確認し、下書きとして登録してブロックエディターで確認します。
10. 次の記事は「新しい記事を開始する」から、新しい管理IDで開始します。

通常はChatGPTでヒアリング・構成承認・本文承認・画像とPDF計画確認・画像の個別制作と採用承認を進め、全体の最終承認後に記事CSV v2を1回受け取ります。実ファイルを取得・ZIP化・添付できる環境だけ一括受け取りが可能です。できない環境は個別保存です。ZIPはパソコンで展開してからCSVと画像を登録してください。ZIP直接取り込みはありません。PNGを実変換せず.webpへ改名しません。「完成した原稿を取り込む」でCSVをアップロードし、資料計画を確認してWordPress標準メディアで画像・PDFをまとめて登録または既存から選択し、各識別子に対応付けてプレビューを更新します。実名が変わっても明示的に対応付けでき、同名ファイルは自動採用しません。URLやAttachment IDをCSVへ推測記入しません。未配置は警告と確認用段落を残すことを承認したうえで下書きにできます。画像不要なら資料工程は省略します。事前の画像・PDF管理と、承認済み原稿を貼り付ける記事CSV v1出力は代替手段として保持しています。

記事CSV v2は従来と同じ12列で、media_jsonにfilesを追加します。filesは記事UUID内の識別子をキーとする最大20資料の計画です。推奨名・用途・本文/アイキャッチ/PDF・配置案・alt・キャプション・PDF表示文・比率・生成指示・制作状態を保持します。正確な配置はcontent_jsonの配列順で決まります。対応付けは現在の取り込みプレビュー内に利用者・サイト別で30分間保持し、保存した下書きへ確定した資料記録を残します。プレビューを更新したら改めて確認・承認してください。画像生成や資料内容の自動読取はプラグインでは実行しません。WordPressの標準アップロード検証・容量制限に従います。同一内容のファイルを再アップロードした場合のハッシュ重複排除は行わないので、アップロード済みのファイルは既存メディアから選んでください。

初期設定CSVは記事本文用CSVとは異なります。共通情報・記事の種類・既存カテゴリー等の方針に対応し、未指定の項目や既存記事の種類は削除しません。空欄の値は明示的な消去です。設定が変わったら初期設定プロンプトを取得し直してください。投稿先の有効化・ACF許可・個人情報・記事・画像の変更には対応しません。初期設定の変更前の控えは直近1回を保持し、専用JSONで表示・保存できます。この控えは設定移行JSONとは異なり、自動読み戻しはできません。beforeを参照して各画面で手動復元してください。通常のWordPress APIによる保存のためDBトランザクションではなく、失敗時は可能な範囲で復元して結果を表示します。

管理者は記事の種類を有効・無効にでき、説明、概要の補足、資料の案内、標準投稿タイプ・分類、追加質問を指定できます。追加質問はquestions_jsonのJSON配列で最大10件。key、label、type（text/textarea/select）、help、options、requiredを持ち、requiredは執筆前のヒアリングを意味します。質問は未回答のまま対話へ進めます。記事の種類と実際の投稿権限が一致するものだけを新規選択に表示します。無効化や削除をしても、記録済みの設定を使う作業中の記事は引き続き再開できます。新規選択には出しません。

初期設定プロンプトは既存分類の実際の名前・スラッグ・IDを含みます。新規カテゴリーはschema_version=2のterm_createで提案し、比較と追加承認後にWordPress標準APIで作成できます（categoryのみ、1回20件）。schema_version=1の既存設定CSVも引き続き使えます。相談時の控えを検証でき、投稿先や既存分類の同一性を確認できる場合は、異なるcontext_revisionのCSVも項目単位で照合します。競合には追加承認が必要です。作成済みカテゴリーの名前・スラッグ・方針が完全一致する再取り込みは変更なしとし、重複作成・既存カテゴリーの上書きは行いません。不一致の場合は実IDを使って最新資料から再相談します。相談時の控えがない・期限切れ・分類の改名等ではCSVの再生成が必要です。識別値だけを手動で書き換えません。保留項目はCSVから省略し、既存値を空欄で消去しません。

基本・詳細は同じ設定領域への差分です。次のCSVを読み込むと比較対象が切り替わりますが、保存済み設定は保持します。未適用の比較の置き換えは明示承認が必要です。詳細画面ではサイト情報・カテゴリー作成等を含むCSVを基本画面へ案内します。基本画面でも詳細項目だけのCSVを認識して対象を表示します。貼り付け欄は上級者向けの折りたたみ内にあります。完全な変更なしの場合は設定も直近の変更前の控えも書き換えません。

新画面からの保存では、共有情報・記事の種類・選択済み分類の方針をサーバーで記録します。同じ記事では保持し、「保存時に管理者の最新設定を採用する」、記事の種類の変更、新しい記事の開始で更新します。権限・分類の実在性・管理者の禁止事項・投稿者情報の利用許可は毎回確認します。未選択の分類候補、品質警告、既存記事の参照範囲、資料・ACF許可は現行設定を使います。スナップショットのない旧記事は従来動作を維持します。新規下書きへの取り込み時も開始設定を記録し、CSV確認後に記録が変われば再検証を求めます。既存の取り込み済み下書きを選ぶだけで当時の設定へ自動復帰する機能は今回含みません。

== Frequently Asked Questions ==

= APIキーは必要ですか？ =
不要です。プラグインは外部AIに自動送信しません。利用者が生成した文章を自分でChatGPTに貼り付けます。

= 投稿を作成・公開できますか？ =
専用CSVから新規下書きへ登録できます。「下書きの更新」では本人の管理ID付き下書き1件のタイトル・本文・抜粋を、対象と差分を確認して更新できます。自動公開・予約公開は行いません。

= 下書き更新で何が変わりますか？ =
タイトル・本文・抜粋を全文置換し、更新日時を変更します。分類・アイキャッチ・ACF・SEO案・著者・スラッグは保持します。元の専用CSVを1記事だけにして修正し、管理ID・投稿先・スラッグ・draftを変えず、分類・メディア・ACF・SEO列を{}にして専用画面へ貼り付けてください。新規取り込み画面では既存記事を更新しません。

= 更新前の内容へ戻せますか？ =
直近の更新前の3項目を控えとして保存します。対象を選び直すと全文を表示でき、必要に応じて標準エディターで手動で戻せます。自動復元はしません。確認後の変更・権限変更・同時編集を検出したら上書きを止めます。結果が不明なときは自動再試行せず、標準エディターで確認してください。

= 更新に通常の保存連携は使えますか？ =
今回の更新は競合防止の条件付きSQLを使い、通常のsave_post・post_updated等の保存フックは発火しません。サイト固有の保存連携が必要なら標準エディターを使ってください。保存前フィルターで本文等が変わる場合も停止します。実WordPressとMySQLでの確認は別途必要です。

= CSVの制限はありますか？ =
UTF-8、1MB以下、1回20記事までです。本文は構造化JSONとし、スラッグは英小文字・数字とハイフンを使います。分類は登録済みterm IDで指定します。表のセルと説明文、資料の説明・alt・キャプションは各2000バイト以下の平文です。画像・PDFを含む記事は現在の記事の対応表で照合するため、その記事の管理IDを使います。ACFは管理者が許可したフィールドキーと型だけを受け付けます。

= ACFは必須ですか？ =
必須ではありません。連携の初期値はすべて無効です。使う場合は管理者が「ACF連携」で投稿先ごとに許可する項目を選びます。投稿タイプだけで表示条件が決まるグループを対象とし、許可後に型・選択肢等が変わった場合は再確認が必要です。Repeater・Relationship・Flexible Content等には未対応です。ACFの独自検証フックや利用テーマまで含む動作は実機で確認してください。

= 取り込みで一部の保存に失敗した場合は？ =
行ごとの結果と、作成済み下書きがあればそのIDを表示します。作成した下書きを自動削除しません。投稿一覧を確認し、既存記事を更新する目的で同じCSVを再実行しないでください。

= 保存できる記事条件はいくつですか？ =
同じサイトの同じ利用者につき1件です。次の保存で置き換えます。

= 個人設定を保存すると公開されますか？ =
公開されません。全項目の初期値は「使わない」です。「使わない」の値は生成する相談プロンプトからも除外します。「AIの参考のみ」と「記事への掲載可」は条件を分けて渡します。実際の原稿を利用者が確認する必要があります。

= 過去に保存した記事の種類は使えますか？ =
使えます。制作工程の新しい項目は「一般ブログ・コラム／AIが推奨」を初期表示します。記事の種類を必要に応じて選び直して保存してください。既存記事の種類を名前だけで自動変更しません。

= プロンプトが表示されなくなりました =
記事条件や共通設定、個人情報の利用範囲等が変わった場合、以前の文面を表示しません。確認・プロンプト出力で現在の内容を確認し、再生成してください。

= 個人設定は全員で共有されますか？ =
このプラグインの画面では本人の設定だけを編集・参照します。同じ利用者でもサイトごとに保存します。サイト共通設定やWordPress標準のユーザープロフィールは変更しません。

= アンインストールで設定は消えますか？ =
自動削除はしません。停止・削除後も設定はデータベースに残ります。

= 設定を別サイトへ移せますか？ =
管理者の「設定の移行」で共有設定をJSONとして保存・読み込みできます。サイト共通設定と投稿先は置換し、記事の種類はIDで更新・追加します。適用前に変更内容を確認し、URL・団体名・連絡先も見直してください。個人設定・記事・カテゴリー設定・画像/PDF対応表・ACF連携は含みません。JSONはUTF-8・1MB以下・記事の種類100件まで。直近の適用前の控えも保存できます。控えを再読み込みしても追加された記事の種類は自動削除されません。

= 既存記事と内容が重なるか相談できますか？ =
管理者が「既存記事の確認」で参照範囲と方針を設定し、公開・パスワードなしの記事の索引を50件ずつ作成します。投稿先とは別に固定ページも参照できます。記事条件の保存後、検索やID指定で最大5件を選択し、見出し・抜粋だけか、抽出本文も含めるかを確認して保存してください。確認・プロンプト出力の相談プロンプトに反映され、新規作成・追記・別の切り口・保留や、次の記事の提案を相談できます。
検索は語句の一致であり、意味的な重複判定やサイト全体の網羅ではありません。本文は最大8000文字。動的・独自ブロック、ACF、画像内文字、PDFは比較しません。元記事や記事条件が変わった場合は再確認が必要です。追記は標準エディターで行い、統合・削除・canonical変更は自動実行しません。

= 「別の処理が実行中」と表示された場合は？ =
処理中のロックは解除しません。通常は処理終了時とPHPの終了処理で、自分が取得したロックだけを解除します。この版で作成したロックは、15分以上経過し、単一のMySQL/MariaDB接続でデータベース排他ロックを取得できる場合に限り、次回操作時に復旧します。旧形式・期限不明のロックや排他確認ができない環境では自動解除しません。解消しない場合は、同時実行や実際の保存結果を管理者が確認してください。処理失敗後に保存済みの記事・設定を自動的に戻す機能ではありません。DB接続の切断・再接続、複数DBへの振り分けを含む構成は別途実機検証が必要です。

= CSVの形式エラーが出た場合は？ =
表示された行・列・項目名を確認してください。引用符が閉じていない場合は、そのレコードの開始行を表示します。JSONエラーはcontent_json等の項目名を表示します。CSVを作成したAIにエラー内容を伝え、他の原稿・画像識別子を維持したまま再出力を依頼できます。検証を無視した保存や壊れたCSVの自動修復は行いません。

= 新しい相談の種類と進め方は？ =
「書きたいことが決まっている」「何を書くかから相談」「ネタ・タイトルだけ相談」をカードで選びます。通常制作では「相談しながら」「なるべくAIにお任せ」「添削だけ」を選べます。添削は原稿が必要で、テーマ探しとの組み合わせは利用できません。添削原稿は平文・3万バイトまで。非表示にした入力は保持しますが、そのモードの相談文には含めません。
管理者はサイト・事業情報で新しい記事の標準の進め方を指定できます。従来値は相談しながら。保存済み作業には遡って適用しません。お任せも重要な事実確認・最終承認・画像1枚ずつの承認を維持します。

= ネタ・タイトル相談は既存記事を参照しますか？ =
利用者向けの参照選択欄はなく、管理者が参照を許可している場合は標準で、許可した公開・パスワードなしの記事の最新50件までのタイトル・URL・抜粋を渡せます。所属カテゴリーは現在の登録状態から取得し、更新日時が一致する索引があれば見出しも渡します。現在のカテゴリー名・目的・掲載する内容／しない内容・想定読者も、利用可能な投稿先と権限の範囲で渡します。本文全体・非公開記事・検索需要データは含みません。分類は最大100件・情報量の上限があり、記事も情報量の上限で50件未満になる場合があります。需要は仮説として扱います。初回5件程度の案を相談し、本文やCSVを作らず終了できます。ChatGPTへのリンクはなく、スクロール欄の相談文をボタンで全文コピーして手動で貼り付けます。

= タイトルだけ下書きにできますか？ =
ネタ・タイトル相談のSTEP2で採用タイトルを貼り付け、操作と投稿先を確認すると、CSVを使わず本文が空の新規下書きを作成できます。既存記事は上書きしません。作成後は標準エディターで続きを編集してください。同じ制作IDで再登録はできません。下書きをまだ作っていない場合は、採用案を記事制作へ引き継ぐこともできます。

= 新しいSTEP3とSTEP4の違いは？ =
STEP3はCSV読み込みと画像・PDFの配置、STEP4は投稿先・分類・画像状態を確認して下書き保存です。完成イメージを大きく表示せず、必要なら本文と画像配置を開いて確認できます。テーマ適用後の表示・編集・保存は登録後の標準エディターで確認します。今回の変更は実WordPressと実ChatGPT対話では未検証です。
